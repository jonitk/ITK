# In The Kitchen — inthekitchen.is

The marketing site for In The Kitchen, built with [Astro](https://astro.build) and
hosted on Netlify. Design by Jules Haggard.

## Where things live

| What | Where |
|---|---|
| Deep Reads articles | `src/content/deep-reads/<url-slug>.md` (one Markdown file each) |
| FAQ (every page) | `src/data/faqs.ts` |
| Business facts for search engines (name, booking link, LinkedIn…) | `src/lib/site.ts` |
| Homepage sections | `src/components/home/*.astro` (one file per section, in page order in `src/pages/index.astro`) |
| Navigation, footer | `src/components/Nav.astro`, `src/components/Footer.astro` |
| Page titles, descriptions, preview images | the `<BaseLayout …>` props at the top of each file in `src/pages/` |
| Styles | `public/styles/webflow.css` (base), `src/styles/*.css` (per page) |
| Redirects | `netlify.toml` |
| Social preview images | `public/og/*.png`, generated by `scripts/og-images.py` |

## Publishing a Deep Read

1. Add `src/content/deep-reads/<slug>.md`. The file name becomes the URL
   (`/deep-reads/<slug>/`). Front matter:

   ```yaml
   ---
   title: "Article title"
   description: "One or two sentences for the list page and search results."
   dek: "Subheading under the title."
   date: 2026-10-20
   order: 1            # position on the Deep Reads list (1 = first)
   thumbnail: "/assets/deep-reads/<slug>-card.png"
   bottomLine: "Optional yellow summary box."
   # readTime: "12 min read"   # optional; calculated from word count otherwise
   ---
   ```

2. Write the body in Markdown. A paragraph starting with `> ` becomes a yellow
   call-out box. Images can be plain HTML `<figure>` blocks.
3. Put the card image in `public/assets/deep-reads/`.
4. Run `python3 scripts/og-images.py` to make its social preview image.

The sitemap, `llms.txt`, structured data and the Deep Reads list update themselves.

## Making changes

- Work on a branch and open a pull request. Netlify builds a private preview
  for every pull request; merge to `main` to publish.
- Every push also runs the GitHub "Build check", which fails if the site
  doesn't build and saves the output to a `builds/<branch>` branch for
  page-by-page comparison.

## Local development

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # output in dist/
```
